# Datos Crudos (Raw)

Esta carpeta contiene los datos originales utilizados en el proyecto antes de cualquier procesamiento, limpieza o transformación.

Los archivos almacenados aquí corresponden a fuentes oficiales y datos abiertos utilizados para el análisis ambiental y geoespacial del sistema.

---

# Objetivo

Mantener una copia organizada y trazable de los datos originales utilizados en el proyecto para garantizar:

- reproducibilidad
- transparencia
- trazabilidad de resultados
- validación técnica
- control de versiones de datasets

---

# Fuentes de Datos

Los datos provienen de diferentes fuentes abiertas y entidades oficiales.

## Fuentes principales

- Datos Abiertos Colombia
- IDEAM
- CAR
- ERA5
- CHIRPS
- Sentinel-2
- Landsat

---

# Tipos de Datos

La carpeta puede incluir:

- archivos CSV
- tablas climáticas
- registros ambientales
- datos hidrológicos
- datos meteorológicos
- capas geoespaciales
- muestras de entrenamiento
- series temporales
