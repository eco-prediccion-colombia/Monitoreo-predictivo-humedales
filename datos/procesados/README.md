# Datos Procesados

Esta carpeta contiene los datos transformados y procesados a partir de las fuentes originales del proyecto.

Los archivos aquí almacenados corresponden a datasets preparados para análisis geoespacial, modelado, validación y visualización.

---

# Objetivo

Organizar los datos derivados del procesamiento técnico y analítico del sistema para facilitar:

- análisis temporal
- entrenamiento de modelos
- validación
- generación de métricas
- visualización
- reproducibilidad del proyecto

---

# Procesos Aplicados

Los datos procesados pueden incluir transformaciones como:

- limpieza de datos
- filtrado temporal
- normalización
- generación de índices espectrales
- integración de variables climáticas
- recorte espacial
- consolidación de datasets
- extracción de características

---

# Tipos de Datos

La carpeta puede incluir:

- datasets limpios
- tablas procesadas
- variables derivadas
- índices espectrales
- datos integrados
- muestras clasificadas
- series temporales
- capas geoespaciales procesadas
