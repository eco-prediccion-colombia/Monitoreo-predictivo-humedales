# Datos Climáticos Procesados

Esta carpeta contiene variables climáticas procesadas utilizadas en el análisis ambiental y predictivo del proyecto.

Los datasets aquí almacenados corresponden a información climática transformada y preparada para integración con modelos geoespaciales y análisis temporal.

---

# Objetivo

Organizar variables climáticas procesadas para apoyar:

- análisis ambiental
- monitoreo ecológico
- análisis temporal
- modelado predictivo
- integración geoespacial
- generación de escenarios

---

# Fuentes de Datos

Las variables climáticas provienen principalmente de:

- ERA5
- CHIRPS
- IDEAM
- Datos Abiertos Colombia

---

# Variables Climáticas

Los datasets pueden incluir variables como:

- precipitación
- temperatura
- humedad
- evaporación
- variables atmosféricas
- acumulados temporales
- promedios climáticos

---

# Procesos Aplicados

Los datos procesados pueden incluir:

- limpieza de registros
- consolidación temporal
- filtrado espacial
- normalización
- integración multifuente
- generación de series históricas
- cálculo de estadísticas

---

# Aplicaciones dentro del Proyecto

Las variables climáticas se utilizan para:

- análisis de dinámica ecológica
- estudio de tendencias ambientales
- apoyo a clasificación supervisada
- evaluación temporal
- construcción de escenarios predictivos
