# Datos Intermedios (`interim`)

Esta carpeta contiene los datasets parcialmente procesados y estandarizados del proyecto **Monitoreo Predictivo de Humedales**.

Los archivos aquí almacenados provienen de la carpeta `raw`, pero ya han pasado por procesos iniciales de limpieza, homologación y transformación.

---

# Objetivo

Centralizar los datos preparados para:

- integración multivariable
- análisis exploratorio
- generación de features
- modelado predictivo
- visualización
- entrenamiento de modelos de IA
