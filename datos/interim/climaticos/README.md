# Datos Climáticos

Esta carpeta contiene los datasets climáticos utilizados en el proyecto **Monitoreo Predictivo de Humedales**.

Las variables aquí almacenadas permiten analizar la relación entre las condiciones atmosféricas y la dinámica ecológica de la Laguna de Fúquene, especialmente la proliferación del buchón de agua.

---

# Objetivo

Centralizar información climática relevante para:

- análisis temporal
- correlaciones ambientales
- generación de features
- modelado predictivo
- validación ecológica
- análisis estacional

---

# Variables climáticas actuales

## Temperatura
Variables mensuales provenientes de estaciones hidrometeorológicas y fuentes abiertas.

Incluye:
- temperatura media
- temperatura máxima
- temperatura mínima

---

## Precipitación
Series históricas de lluvia mensual utilizadas para analizar:

- escorrentía
- aportes hídricos
- variabilidad climática
- posibles impactos sobre expansión vegetal

---

## Viento
Datos de:
- velocidad
- dirección del viento

utilizados para estudiar:
- dispersión superficial
- dinámica de cobertura vegetal flotante
- transporte de material orgánico

---

## Normales climatológicas
Promedios climáticos históricos utilizados como referencia de comportamiento ambiental regional.

---

# Fuentes principales

- CAR

---

# Importancia ecológica

Las variables climáticas son fundamentales debido a que el buchón de agua responde directamente a factores como:

- temperatura
- disponibilidad hídrica
- evaporación
- estacionalidad climática
- condiciones atmosféricas regionales
