# Datos

Esta carpeta contiene conjuntos de datos utilizados en el proyecto.

Incluye:
- datos abiertos ambientales
- datos climáticos
- muestras de entrenamiento
- series temporales
- archivos CSV
- metadatos

Fuentes principales:
- Sentinel-2
- Landsat
- ERA5
- CHIRPS
- IDEAM
- CAR
- Datos Abiertos Colombia

Nota:
Los datasets de gran tamaño no se almacenarán directamente en el repositorio.
