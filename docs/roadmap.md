# Roadmap del Proyecto

## Sistema de Inteligencia Ambiental Predictiva para Humedales Colombianos

---

# Visión General

El proyecto busca desarrollar una plataforma de inteligencia ambiental basada en inteligencia artificial, análisis geoespacial y datos abiertos para monitoreo y proyección ecológica de humedales colombianos.

El caso piloto corresponde a la Laguna de Fúquene, ecosistema afectado por procesos de degradación ambiental y expansión de vegetación invasora.

El roadmap organiza el desarrollo técnico, científico y visual del sistema mediante fases progresivas orientadas a construir una solución robusta, escalable y competitiva.

---

# Objetivos Estratégicos

- consolidar una arquitectura reproducible
- desarrollar modelos de monitoreo ambiental
- integrar datos abiertos nacionales
- implementar análisis temporal multianual
- construir escenarios predictivos
- desarrollar visualización interactiva
- fortalecer narrativa técnica y ambiental
- facilitar escalabilidad a otros humedales

---

# Fase 1 — Base Científica y Procesamiento

## Objetivo

Construir una base técnica sólida para el análisis ambiental y procesamiento geoespacial.

## Componentes principales

- definición de región de estudio
- integración de datos abiertos
- procesamiento satelital
- limpieza de imágenes
- generación de mosaicos
- cálculo de índices espectrales
- organización de arquitectura del proyecto

## Tecnologías involucradas

- Google Earth Engine
- Sentinel-2
- Landsat
- Python

## Estado esperado

- pipeline funcional
- estructura organizada
- datasets consolidados

---

# Fase 2 — Clasificación y Validación

## Objetivo

Implementar modelos de clasificación supervisada y evaluar desempeño técnico.

## Componentes principales

- generación de muestras
- entrenamiento Random Forest
- clasificación supervisada
- generación de mapas temáticos
- evaluación cuantitativa
- validación del modelo

## Métricas previstas

- matriz de confusión
- accuracy
- precision
- recall
- F1-score

## Estado esperado

- modelo validado
- resultados reproducibles
- métricas consistentes

---

# Fase 3 — Análisis Temporal

## Objetivo

Construir series históricas para detectar cambios ecológicos y tendencias espaciales.

## Componentes principales

- análisis multitemporal
- evolución de coberturas
- detección de expansión del buchón
- análisis de tendencias
- comparación anual

## Periodo objetivo

2016–2025

## Estado esperado

- series históricas robustas
- análisis temporal consolidado
- identificación de zonas críticas

---

# Fase 4 — Modelos Predictivos

## Objetivo

Construir escenarios prospectivos ecológicos mediante inteligencia artificial y análisis temporal.

## Componentes principales

- análisis de patrones históricos
- proyección de escenarios
- identificación de tendencias
- estimación de zonas de riesgo
- simulación ecológica

## Escenarios previstos

- 2030
- 2040
- 2050

## Estado esperado

- escenarios prospectivos
- visualización predictiva
- análisis de riesgo ecológico

Nota:
Las proyecciones corresponden a escenarios probabilísticos y no predicciones exactas.

# Visión del Proyecto

El objetivo del sistema no es únicamente realizar clasificación satelital.

La visión del proyecto es construir una plataforma de inteligencia ambiental predictiva basada en IA y datos abiertos para apoyar monitoreo ecológico, análisis territorial y resiliencia ambiental en humedales colombianos.
