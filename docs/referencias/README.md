# Referencias Técnicas y Científicas

Esta carpeta contiene documentos técnicos, artículos, informes institucionales y referencias metodológicas utilizadas para sustentar el desarrollo del proyecto **Monitoreo Predictivo de Humedales**.

---

# Objetivo

Centralizar la documentación que respalda:

- variables ambientales utilizadas
- dinámica ecológica del buchón
- criterios hidrológicos
- metodologías de monitoreo
- análisis de calidad de agua
- modelación climática y geoespacial
- estrategias de manejo ambiental

---

# Contenido

## Documentos institucionales
Informes provenientes de:

- CAR
- IDEAM
- Datos Abiertos Colombia
- entidades ambientales
- estudios académicos

---

# Uso dentro del proyecto

Estos documentos sirven para:

- justificar variables del modelo
- validar hipótesis ecológicas
- contextualizar la problemática ambiental
- apoyar el diseño metodológico
- fortalecer la narrativa científica del proyecto
