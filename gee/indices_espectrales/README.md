# Índices Espectrales

Esta carpeta contiene los algoritmos y funciones utilizadas para calcular índices espectrales aplicados al monitoreo ecológico de humedales.

## Objetivo

Extraer información biofísica y ambiental a partir de imágenes satelitales mediante transformaciones espectrales.

## Índices implementados

### NDVI
Índice de vegetación utilizado para evaluar cobertura vegetal y vigor fotosintético.

### NDWI
Índice orientado a la detección de cuerpos de agua superficiales.

### MNDWI
Versión modificada del NDWI utilizada para mejorar la separación entre agua y superficies terrestres.

### FAI
Floating Algae Index utilizado para detectar vegetación flotante y posibles expansiones de buchón de agua.

## Aplicaciones

- detección de vegetación invasora
- monitoreo hídrico
- análisis ecológico
- clasificación supervisada
- análisis temporal

## Resolución espacial

Los índices se calculan principalmente sobre imágenes Sentinel-2 de 10 metros de resolución espacial.
