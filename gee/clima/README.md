# Datos Climáticos

Esta carpeta contiene procesos de extracción, integración y análisis de variables climáticas abiertas asociadas al comportamiento ecológico de la Laguna de Fúquene.

## Objetivo

Integrar información climática al sistema de monitoreo predictivo ambiental.

## Fuentes de datos

### CHIRPS
Datos satelitales de precipitación.

### ERA5-Land
Datos climáticos globales de reanálisis atmosférico.

## Variables climáticas

- precipitación
- temperatura
- velocidad del viento
- dirección del viento

## Aplicaciones

- correlación clima-ecosistema
- análisis temporal
- predicción ambiental
- comportamiento hidrológico
- análisis multivariable

## Escala temporal

Mensual.

## Importancia científica

La integración climática permite comprender posibles relaciones entre condiciones atmosféricas y expansión de vegetación invasora.
