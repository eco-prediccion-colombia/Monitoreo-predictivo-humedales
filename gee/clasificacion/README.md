# Clasificación Supervisada

Esta carpeta contiene los procesos relacionados con entrenamiento, validación y aplicación de modelos de clasificación supervisada para el monitoreo ecológico de humedales.

## Objetivo

Identificar coberturas ambientales mediante algoritmos de inteligencia artificial y aprendizaje automático.

## Modelo implementado

### Random Forest

Modelo de clasificación supervisada basado en árboles de decisión utilizado para:

- detección de buchón de agua
- separación agua/tierra
- análisis multiclase
- clasificación temporal

## Clases principales

- agua
- buchón de agua
- tierra firme y juncales

## Variables predictoras

- bandas espectrales
- NDVI
- NDWI
- MNDWI
- FAI

## Validación

Los modelos son evaluados mediante:

- matriz de confusión
- accuracy
- precision
- recall
- F1-score
- kappa

## Objetivo estratégico

Construir modelos robustos capaces de apoyar procesos de monitoreo ambiental y análisis ecológico mediante inteligencia artificial.
