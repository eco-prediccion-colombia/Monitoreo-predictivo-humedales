# Exportaciones

Esta carpeta contiene procesos de exportación y generación de productos derivados del análisis geoespacial.

## Objetivo

Automatizar la generación de resultados para análisis, almacenamiento y visualización externa.

## Productos exportados

- archivos CSV
- estadísticas temporales
- capas raster
- resultados de clasificación
- métricas ambientales

## Destinos de exportación

- Google Drive
- almacenamiento local
- plataformas cloud
- sistemas externos de análisis

## Formatos utilizados

- CSV
- GeoTIFF
- SHP
- imágenes raster

## Aplicaciones

- integración con dashboards
- análisis estadístico
- ciencia de datos
- visualización geoespacial
- construcción de modelos predictivos
