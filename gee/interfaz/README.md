# Interfaz y Visualización

Esta carpeta contiene componentes de visualización, control interactivo y herramientas de inspección espacial desarrolladas sobre Google Earth Engine.

## Objetivo

Facilitar la exploración visual y validación interactiva de resultados geoespaciales.

## Componentes implementados

- paneles interactivos
- controles temporales
- visualización multibanda
- capas clasificadas
- mapas dinámicos
- control de calidad visual

## Funcionalidades

- selección temporal
- inspección mensual
- visualización multiclase
- exploración espectral
- comparación espacial

## Capas principales

- imágenes satelitales
- clasificación supervisada
- índices espectrales
- límites del ROI

## Objetivo estratégico

Construir herramientas visuales que apoyen procesos de monitoreo ambiental y análisis territorial.
