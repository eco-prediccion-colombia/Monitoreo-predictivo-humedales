# Google Earth Engine

Esta carpeta contiene scripts y procesos desarrollados en Google Earth Engine (GEE).

Incluye:
- procesamiento satelital
- cálculo de índices espectrales
- clasificación supervisada
- análisis temporal
- exportación de resultados
- generación de mapas

Sensores principales:
- Sentinel-2
- Landsat

Índices utilizados:
- NDVI
- NDWI
- MNDWI
- FAI
