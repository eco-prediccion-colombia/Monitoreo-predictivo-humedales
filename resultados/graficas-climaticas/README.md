# Análisis Climático Histórico — Laguna de Fúquene

Esta carpeta contiene gráficas y resultados preliminares asociados al análisis climatológico histórico de la Laguna de Fúquene.

Los análisis buscan identificar patrones ambientales y tendencias climáticas relevantes para comprender dinámicas ecológicas del humedal y apoyar el desarrollo de modelos predictivos.

---

# Objetivo

Analizar variables climáticas históricas que puedan influir en:

- expansión de vegetación invasora
- dinámica hídrica
- cambios ecológicos
- comportamiento ambiental del humedal
- escenarios futuros

---

# Variables Analizadas

Los análisis incluyen variables como:

- precipitación
- temperatura media
- brillo solar
- evapotranspiración potencial (ETo)

---

# Periodos Climáticos Evaluados

Se comparan diferentes épocas climatológicas históricas:

- 1961–1990
- 1971–2000
- 1981–2010
- 1991–2020

Esto permite identificar:

- tendencias ambientales
- variabilidad climática
- cambios multitemporales
- posibles alteraciones ecológicas

---

# Fuentes de Datos

Los datos utilizados provienen de:

- IDEAM
- series climatológicas históricas
- datos abiertos ambientales
- registros meteorológicos oficiales

---

# Relación con el Proyecto

El análisis climático complementa el monitoreo satelital y fortalece el componente de inteligencia ambiental del sistema.

Estas variables podrán integrarse posteriormente en:

- análisis temporal
- modelos predictivos
- evaluación ecológica
- detección de patrones ambientales
