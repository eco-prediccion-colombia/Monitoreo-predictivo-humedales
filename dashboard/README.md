# Dashboard

Esta carpeta contiene los componentes de visualización interactiva del proyecto.

Aquí se integrarán:
- mapas interactivos
- visualización temporal
- indicadores ambientales
- análisis geoespacial
- paneles de monitoreo
- proyecciones ecológicas

El objetivo es facilitar la interpretación de datos ambientales mediante herramientas visuales accesibles y escalables.
